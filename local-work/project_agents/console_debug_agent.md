## Project Context

The Console Debug Agent is a specialized debugging agent dedicated to monitoring, analyzing, and validating console output to ensure JavaScript functionality matches expected behavior. This agent serves as a "console watchdog" that catches discrepancies between what code should produce and what actually appears in the console.

## Example Workflow

### **Scenario: Carousel Animation Issue**

#### **1. Console Analysis**
```
Console Debug Agent Analysis:
- Expected: "Animation initialized with 300s speed"
- Actual: "Animation: 0s ease 0s 1 normal none paused none"
- Discrepancy: Animation duration is 0s instead of 300s
- Issue: CSS animation not being applied
```

#### **2. Debugging Recommendations**
```
Console Debug Agent Recommendations:
- Check CSS loading order
- Verify CSS syntax
- Check for CSS conflicts
- Force animation with JavaScript
- Validate CSS animation definition
```

#### **3. Validation Protocol**
```
Console Debug Agent Validation:
- Expected: "Animation: scrollCarousel 300s linear infinite"
- Actual: Check console for correct animation
- Validation: Verify animation is running
- Success: Carousel animates smoothly
```
