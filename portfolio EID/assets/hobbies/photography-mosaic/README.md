# Photography Mosaic Images Setup

## 📸 Required Photography Mosaic Images

To complete the photography mosaic gallery, please add the following images to this folder:

### **File Names & Descriptions:**

1. **`landscape.jpg`** - Landscape Photography
   - Description: Breathtaking landscape shots
   - Suggestion: Desert landscapes, mountains, seascapes
   - Size: High resolution for xlarge mosaic item

2. **`portrait.jpg`** - Portrait Photography
   - Description: Human stories through images
   - Suggestion: Candid portraits, environmental portraits
   - Size: High resolution for large mosaic item

3. **`street.jpg`** - Street Photography
   - Description: Urban life captured
   - Suggestion: Street scenes, city life, candid moments
   - Size: Medium resolution for medium mosaic item

4. **`architecture.jpg`** - Architecture Photography
   - Description: Design in structure
   - Suggestion: Buildings, structures, architectural details
   - Size: Medium resolution for small mosaic item

5. **`nature.jpg`** - Nature Photography
   - Description: Wild beauty
   - Suggestion: Wildlife, natural scenes, close-ups
   - Size: Medium resolution for xsmall mosaic item

6. **`travel.jpg`** - Travel Photography
   - Description: Adventures documented
   - Suggestion: Travel destinations, cultural moments
   - Size: High resolution for large mosaic item

7. **`event.jpg`** - Event Photography
   - Description: Moments preserved
   - Suggestion: Events, celebrations, gatherings
   - Size: Medium resolution for medium mosaic item

8. **`abstract.jpg`** - Abstract Photography
   - Description: Creative vision
   - Suggestion: Abstract compositions, artistic shots
   - Size: Medium resolution for small mosaic item

## 📋 Setup Instructions:

1. **Select your best photos** from your 500px portfolio
2. **Crop them appropriately** for the mosaic layout
3. **Rename them** according to the file names above
4. **Place them** in this `assets/photography-mosaic/` folder
5. **Ensure they are JPG format** for optimal loading

## 🎯 Image Requirements:

- **Format:** JPG/JPEG
- **Quality:** High resolution for crisp display
- **Aspect Ratios:** Various (will be cropped to fit mosaic)
- **File Size:** Optimize for web (under 1MB each)
- **Content:** Diverse photography styles and subjects

## 🔧 Mosaic Layout:

The mosaic uses different sizes for visual interest:
- **xlarge:** 600x300px (landscape)
- **large:** 400x250px (portrait, travel)
- **medium:** 300x200px (street, event)
- **small:** 250x150px (architecture, abstract)
- **xsmall:** 200x120px (nature)

## 📱 Features:

- **Lightbox functionality** - Click to view full size
- **Hover effects** - Overlay with title and description
- **Responsive design** - Adapts to all screen sizes
- **Lazy loading** - Optimized performance

## 🎨 Styling:

- **Glass morphism overlays** with blur effects
- **Smooth transitions** and hover animations
- **Consistent with design system** colors and effects

## 📊 Performance Tips:

- **Optimize images** for web (compress without losing quality)
- **Use appropriate sizes** for each mosaic item
- **Test loading speed** on different devices
- **Ensure accessibility** with proper alt text

## 🔄 Alternative Setup:

If you prefer different categories or want to use different images:
- Simply rename your images to match the file names above
- Or update the HTML file paths in `about.html`
- The mosaic layout will automatically adapt to your images
